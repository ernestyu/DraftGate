# G2 — Scope & Branch Control

## Goal

Decide which material belongs to the main line and which material may serve only as evidence, mechanism, boundary, or a separate-article candidate.

## Reader outcome

The article has one center. The reader is not forced to switch between multiple competing large questions.

## Allowed

- classify existing material as core / support / boundary / separate-article candidate;
- remove or demote side branches that compete with the center;
- make the minimum scope adjustment needed to keep the main question intact.

## Forbidden

- redesign section order;
- perform sentence-level rewriting;
- change paragraph style;
- introduce new ideas unrelated to the main question;
- perform G3 architecture work.

## Exit

The main line and supporting branches have clear roles, and there are no two co-equal centers.

Mark G2 PASS and stop.
