# G2 — Scope & Branch Control

## Goal

确定哪些内容属于主线，哪些只能作为证据、机制、边界或另一篇文章的候选。

## Reader outcome

全文只有一个中心，读者不会在多个大问题之间来回切换。

## Allowed

- 将现有内容分类为 core / support / boundary / separate-article candidate
- 删除或降级明显抢夺中心的支线
- 为保持主问题完整做最小范围调整

## Forbidden

- 重新设计章节顺序
- 做逐句改写
- 调整段落风格
- 新增与主问题无关的新观点

## Exit

主线和支线角色清楚；不存在两个并列中心。标记 G2 PASS 后停止。
