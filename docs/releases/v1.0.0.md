# DraftGate v1.0.0

DraftGate v1.0.0 is the first stable release of the Git-native staged editorial workflow.

It provides the full G1–G7 writing lifecycle, deterministic Git/state validation, cycle-aware evidence and archives, automatic G7 closeout, and Persistent Custom Rules for long-term personal writing profiles.

The release was validated with two real dogfood cycles. The second cycle entered at G3, used a legal G5 NO_CHANGE transition, completed through G7, and closed automatically back to `main` while preserving both cycle archives and evidence refs.

See `CHANGELOG.md` for the detailed release contents.
